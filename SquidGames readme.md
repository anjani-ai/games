Squid Game Inspired Games

A Python-based project that recreates games inspired by the Netflix show Squid Game. Test your skills with games like Red Light, Green Light and Tug of War in this interactive console-based application 

Features 

Red Light, Green Light: Cross the finish line without moving during "Red Light."
Tug of War: Compete against a virtual opponent by rapidly alternating key presses.
Modular code structure for adding more games in the future.
